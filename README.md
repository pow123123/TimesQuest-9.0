# 口诀大冒险 (TimesQuest)

专为 8 岁二年级小朋友打造的纯本地离线 Android 乘法口诀打怪闯关 RPG（无广告、免登录）。

## 核心特性
- **9 大奇幻岛屿 × 36 关 + 无尽勇者塔**：从 1/2/5 启蒙到 6/7/8/9 重点攻坚与全口诀大融合，支持 6 题摸底定级。
- **5 种 RPG 施法与战斗玩法**：极速魔法弹暴击、破盾逆向咒（`□ × 7 = 42`）、符文键盘终极奥义、等积泡泡消除 / 双怪比大小特训、Boss 狂暴格挡弹反 QTE。
- **即刻懂 + 玩得爽**：NanoBanana 奇幻原画、Canvas 魔法弹道粒子与屏震、五声音阶连击合成音效、本地中文 TTS 口诀朗读、答错魔法宝石点阵图拆解 + 2~3 回合后「复仇重测」。
- **零氪金成长收集**：纯答题赚金币升级勇者、解锁 5 把元素法杖（真实改变施法特效）、4 套头饰装扮、4 只每 4 连击自动协击的小萌宠、18 种怪物图鉴与每日宝箱。
- **家长守护中心**：两位数进位加法家长锁、9×9 薄弱口诀热力图与一键钉选特训、每日 15 分钟 / 3 关护眼休息营地。
